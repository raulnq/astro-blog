Shopify is making a significant move away from React Native, returning to native Swift and Kotlin for its mobile applications. The e-commerce giant, which embraced React Native in 2020 for its cross-platform benefits, now states that advancements in large language models (LLMs) have fundamentally altered the economics of mobile development. Shopify's rationale is that LLMs can now sufficiently handle the implementation, translation, testing, and review work across platforms, negating the primary advantage of building features once in React Native. This pivot is supported by their internal “Helix” system, which facilitates gradual, checkpoint-based AI-assisted greenfield rewrites. The company’s "Shop App" was reportedly rebuilt and published in just 12 weeks with AI assistance, and the larger "Shopify App" migration is underway. In terms of open-source contributions, React Native Skia will be forked and maintained by an employee, Flash List will see continued critical support while seeking new stewardship, and ReStyle will be archived.

The announcement has prompted extensive discussion within the developer community. Experts note that Shopify's initial success with React Native, which included outperforming native versions in some cases, highlights the framework's potential. However, the analysis also points to often-overlooked benefits of React Native, such as Over-the-Air (OTA) updates, which enable rapid bug fixes and feature rollouts without lengthy app store review cycles—a capability that native development lacks. Critics suggest Shopify's challenges might have been mitigated by a fuller adoption of tools like Expo, which simplifies React Native development, builds, and OTA updates. Furthermore, while performance and app size are often cited as React Native drawbacks, the framework's newer architecture has significantly improved these areas, and app size differences with native often prove minimal. The evolving landscape of mobile development, heavily influenced by sophisticated AI agents, is increasingly closing the skill gap that once made Meta’s heavily invested React Native team (historically 10x larger than the core React team) an indispensable advantage for developers seeking high-quality native bindings. The perceived slowdown in Meta's investment in its React and React Native teams, coupled with the rising capability of AI to assist in native code generation, suggests a shifting paradigm where the once-critical abstraction layer of React Native might become less essential for teams leveraging advanced AI tooling.
