A new GitHub repository, "NX Native," has garnered significant attention for its capability to convert Nintendo Switch game files into native applications for macOS, iPhone, and iPad. Unlike traditional emulation, this project reconstructs game graphics using Apple's Metal API, delivering titles like Dark Souls Remastered and Super Mario Odyssey as IPAs that run natively on Apple Silicon. This conversion promises enhanced performance, often achieving 60 frames per second even for games originally capped at 30 FPS on Switch, alongside improved visuals due to increased memory limits. Features such as touch controls, controller support, save states, and haptic feedback are fully functional. Hardware requirements include an iPhone 15 Pro or newer, or an iPad with an M1 chip, primarily due to the handling of BC-compressed textures. This development, which requires users to provide their legitimate game files, bypasses traditional emulation entirely, suggesting a significant shift in game portability that could challenge existing console ecosystems. Parallels are already being drawn to a burgeoning PlayStation 5 project aiming for similar native code transformation across Windows, macOS, and Linux platforms.

Simultaneously, the modding community has uncovered methods to unlock hidden AI compute performance in NVIDIA's RTX 20, 30, and 40 series GPUs. Through software modifications that target Tensor Core operations, modders have reportedly nearly doubled teraflops performance for AI workloads without requiring hardware alterations or BIOS flashing. This allows for significantly higher token per second processing, though NVIDIA cautions against these modifications due to potential stability and lifespan risks, as these limits are often set for security and hardware longevity. Separately, the "Cute Fish" Linux distribution has emerged, demonstrating the ability to install and execute macOS applications natively on Linux. While specific technical details are still unfolding, demonstrations show macOS applications running with full windowing system integration and functional menu bars, indicating a sophisticated compatibility layer. These independent yet concurrent breakthroughs signify a period of rapid evolution in software and hardware boundaries, pushing the limits of platform exclusivity and performance optimization.
